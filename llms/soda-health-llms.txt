# Soda Health (Evermore Outcomes)

> Soda Health is a healthcare benefits technology company powering supplemental
> benefits (OTC, healthy food/grocery, flex spending) for Medicare Advantage and
> Medicaid members via a benefits administration and health-wallet platform. The
> company now operates as Evermore Outcomes (sodahealth.com redirects to
> evermoreoutcomes.com). The public developer surface is the Evermore Docs Portal
> API — a Confluence-backed customer documentation portal with magic-link and OIDC
> authentication. This llms.txt was generated by the API Evangelist enrichment
> pipeline from the catalog entry and captured OpenAPI.

## APIs

- [Evermore Docs Portal](https://docs.evermoreoutcomes.com/): Customer-facing product documentation portal API; browse/search Confluence-backed docs, magic-link + OIDC auth.
